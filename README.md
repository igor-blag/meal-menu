# Календарь питания — Meal Menu

WordPress-плагин для управления школьным меню: шаблоны циклов, календарь питания, генерация Excel для ФЦМПО, общественный контроль питания, детский сад.

Работает как со **школами**, так и с **детскими садами**.

## Возможности

- **Шаблоны циклов** — создавайте наборы блюд по дням, импортируйте из XLSX или TM-файлов
- **Календарь питания** — назначайте дни цикла на даты, отмечайте выходные/рабочие дни, копируйте данные между отделениями
- **Excel для ФЦМПО** — генерация ежедневного меню (daily), типового примерного меню (TM), годового план-графика (KP), общественного контроля (OC)
- **Общественный контроль питания** — разделы ФИС ФРДО: положение, горячая линия, диетические меню, анкетирование, отчёты
- **Летний лагерь** — отдельные шаблоны и календарь для пришкольного лагеря
- **Gutenberg-блок** — вставьте календарь на любую страницу, настройте палитру и макет
- **AI-распознавание фото меню** — сфотографируйте меню, перетащите в дропзону — AI заполнит шаблон
- **Публикация файлов** — скопируйте XLSX в публичную папку `/food/` для внешних систем
- **Email-уведомления** — напоминания о незаполненном меню, SMTP-поддержка

## Установка

1. Скачайте последний релиз со [страницы релизов](https://github.com/igor-blag/meal-menu/releases)
2. В WordPress: **Плагины → Добавить новый → Загрузить плагин**
3. Выберите скачанный ZIP и нажмите «Установить»
4. Активируйте плагин

Либо скопируйте папку `meal-menu` в `/wp-content/plugins/`.

## Быстрый старт

### 1. Настройки пищеблока

**Питание → Настройки пищеблока**

- Выберите тип учреждения: **Школа** или **Детский сад**
- Типовые отделения создадутся автоматически
- Отметьте нужные отделения, настройте рабочие дни
- Если у отделений одинаковый цикл — используйте **«Объединить календарь с»**, чтобы вести данные в одном месте
- Добавьте **праздники** — задаются без года, применяются ежегодно. Если дата выпадает на выходной — переносится на понедельник
- Для школы: настройте учебный год, каникулы, утверждающее лицо для TM-файлов

### 2. Шаблоны циклов

**Питание → Шаблоны**

Создайте наборы блюд по дням цикличного меню:

- **Добавить день** — новый пустой шаблон
- **Импорт XLSX** — перетащите файл ежедневного меню в дропзону
- **Импорт TM-файла** — загрузите типовое примерное меню (заменит весь цикл)
- **AI-распознавание** — перетащите фото меню (JPEG/PNG/WebP) — AI заполнит шаблон (требуется настроенный AI-коннектор)

Для каждого дня заполните приёмы пищи: завтрак, обед, полдник, ужин и т.д. Колонки появляются автоматически при добавлении блюд.

### 3. Календарь

**Питание → Календарь**

Ежемесячно назначайте дни цикла на конкретные даты:

1. Выберите вкладку отделения
2. Перейдите на нужный месяц
3. Кликните на первый рабочий день, укажите номер дня меню
4. Нажмите **«Заполнить до конца месяца»** или **«Применить»**
5. После заполнения всех дней — **«Создать файлы»**

### 4. Блок «Календарь питания» (Gutenberg)

В редакторе страницы добавьте блок **«Календарь питания»**:

- Выберите **отделение** — его вкладка будет первой на сайте
- Настройте **палитру** и **макет** в боковой панели
- Если отделения объединены — выберите основное, зависимые будут недоступны для выбора
- Опубликуйте страницу

Также работает шорткод: `[meal_calendar type="sm"]`

### 5. Детский сад

При выборе «Детский сад» в настройках:

- Два типовых отделения: **ясли** (интернатный режим) и **основная группа**
- Разделы каникул, утверждающего лица, публикации XLSX и ОК Питания скрыты
- Доступно объединение календарей отделений
- На сайте отображается только календарь с меню

## Шорткоды

| Шорткод | Описание |
|---|---|
| `[meal_calendar]` | Календарь питания. Атрибуты: `type` (код отделения), `palette`, `layout`, `show_oc` |
| `[meal_day date="2025-09-01" type="sm"]` | Меню на конкретный день |

## Требования

- PHP 8.0+
- WordPress 6.3+
- MySQL 5.7+ или MariaDB 10.3+
- Для генерации Excel: PHP-расширения `ext-zip`, `ext-gd`, `ext-fileinfo`, `ext-xml`, `ext-dom`

## Разработка

```bash
# Клонировать
git clone https://github.com/igor-blag/meal-menu.git

# Установить PHP-зависимости
composer install

# Установить JS-зависимости и собрать блок
npm install
npm run build

# Собрать ZIP-архив для установки в WP
./build.sh
```

## Обновления

Плагин автоматически проверяет новые версии на GitHub. Обновление отображается на странице **Dashboard → Updates**.
