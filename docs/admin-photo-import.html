15. Импорт шаблона с фото (AI-распознавание)

Файлы: includes/class-importer-photo.php

AJAX: wp_ajax_meal_photo_upload, wp_ajax_meal_photo_analyze, wp_ajax_meal_photo_save_template

Начиная с WordPress 7.0 появилась нативная поддержка AI-коннекторов (OpenRouter, Google AI, OpenAI, Anthropic). Плагин использует эту инфраструктуру для распознавания меню с фотографии.

Как это работает

  1. Пользователь перетаскивает JPEG/PNG/WebP-фото меню в дропзону на странице Питание → Шаблоны
  2. Фото загружается во временную директорию wp-content/uploads/meal-menu/ai-import/
  3. Изображение отправляется в AI-провайдер через wp_ai_client_prompt() с визион-моделью
  4. AI возвращает структурированный JSON с перечнем блюд, разбивкой по приёмам пищи, весом и КБЖУ
  5. Открывается модальное окно с редактируемой таблицей результатов
  6. Пользователь может отредактировать данные, выбрать отделение и номер дня, нажать «Сохранить шаблон»
  7. Шаблон создаётся в БД, страница обновляется — новый день отображается в таблице

Поддерживаемые AI-провайдеры

Плагин не привязан к конкретному провайдеру — WordPress AI Client SDK автоматически находит доступный коннектор. Приоритет моделей:

  • google/gemini-2.5-flash — оптимально по скорости/цене (через OpenRouter или Google AI)
  • gemini-2.5-flash — через нативный Google-коннектор
  • gpt-4o-mini — fallback через OpenAI
  • claude-3-haiku — fallback через Anthropic

Требования

  1. WordPress 7.0+
  2. Установленный и настроенный AI-коннектор (Settings → Connectors)
  3. Установленный AI-плагин от WordPress.org (обеспечивает UI для разрешений)
  4. В Tools → Connector Approvals должно быть одобрено использование коннектора плагином «Мониторинг питания»

Маппинг полей

Разные AI-модели могут возвращать поля в разных нотациях. Плагин автоматически нормализует:

Дропзона

Единая дропзона на странице шаблонов принимает как .xlsx, так и изображения. Тип файла определяется автоматически:

  • .xlsx — существующий импорт (ежедневное меню → новый шаблон, TM-файл → замена цикла)
  • JPEG/PNG/WebP — AI-распознавание (создаёт один шаблон)

Тип отделения определяется по активной вкладке.

Обработка ошибок

  • Если AI не настроен — пользователь видит алерт на странице и ошибку при попытке загрузить фото
  • При таймауте запроса (120 сек) — показывается сообщение с предложением повторить
  • Если AI вернул невалидные данные — выполняется повторный запрос с более строгим промптом
  • Ошибки сохраняются в AI Request Logs (Tools → AI Request Logs)

Временные файлы

Загруженные фото хранятся в wp-content/uploads/meal-menu/ai-import/ и автоматически удаляются через 1 час.

Безопасность

  • Доступ только у пользователей с capability manage_meal_menu
  • Проверка nonce на всех AJAX-запросах
  • Валидация MIME-типа загружаемого файла
  • Санітизация всех данных, полученных от AI
