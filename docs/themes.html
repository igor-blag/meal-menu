11. Тематическая система оформления

Файлы: assets/css/themes.css, templates/admin/page-theme.php

Опции: meal_theme_palette, meal_theme_layout

Хуки: wp_ajax_meal_save_theme

Архитектура

Тема = Палитра (цвета) + Стиль (шрифт/отступы/радиус). Оба компонента — это CSS-классы с набором CSS-переменных. На HTML-обёртку .meal-wrapper добавляются классы .palette-* и .layout-*, которые переопределяют значения переменных.

.meal-wrapper { /* значения по умолчанию через var(--meal-*) */ }
.palette-retro   { --meal-primary: #c8580a; --meal-bg: #fdf4e3; ... }
.palette-ocean   { --meal-primary: #0a7a7a; --meal-bg: #f0f8f5; ... }
.layout-classic  { --meal-font: 'Source Serif 4', Georgia, serif; --meal-radius: 2px; }
.layout-modern   { --meal-font: -apple-system, sans-serif; --meal-radius: 8px; --meal-grid-gap: 4px; }
.layout-air      { --meal-font: -apple-system, sans-serif; --meal-grid-gap: 4px; }

Базовый CSS (public.css) использует только var(--meal-*) — никаких жестко заданных цветов. Это позволяет переключать тему без перезагрузки страницы.

Воздушный    — System sans-serif, без рамок, минимум линий, много whitespace

Добавление новой палитры

  1. Добавить блок в themes.css: 
    .palette-xxx {
    --meal-primary: ... ; --meal-bg: ... ; /* все 26 переменных */
}
  2. Добавить элемент в массив $palettes в page-theme.php
  3. Палитра автоматически появится в админке и preview
