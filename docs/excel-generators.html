9. Excel-генерация

Файлы: includes/class-excel-daily.php, class-excel-tm.php, class-excel-kp.php, class-excel-oc.php, class-importer.php

Зависимость: PhpSpreadsheet 2.4 (composer)

Ежедневные xlsx (Excel_Daily)

Генерируется при сохранении дня в календаре и при массовом создании файлов.

  • Формат: YYYY-MM-DD[-suffix].xlsx
  • Шапка: школа, отделение/корпус, день
  • Секции: Завтрак, Завтрак 2, Обед (+ Полдник, Ужин, Ужин 2 для интерната)
  • Жёлтые ячейки — редактируемые, белые — заблокированные (стандартные подразделы)
  • Защита листа паролем
  • Ландшафтная ориентация A4

Типовое меню (Excel_TM)

Генерируется при сохранении sm-шаблона. Файл: tm{year}-{type}.xlsx.

  • Шапка: школа, утверждающее лицо, возрастная категория, дата
  • Строки по дням цикла с группировкой по неделям
  • Итого по завтраку, итого по обеду, итого за день (с формулами SUM)
  • Автоматическое определение количества дней в неделе (5/6/7)

Годовой план (Excel_KP)

Файл: kp{year}-{type}.xlsx. Сетка 10 месяцев × 31 день.

  • Строки: январь–июнь, сентябрь–декабрь
  • В ячейках — номера дней цикла, назначенных на дату
  • При повторной генерации обновляются только значения ячеек (сохраняется форматирование)

OC мониторинг (Excel_OC)

Файл: findex.xlsx. Загружает шаблон data/findex-template.xlsx и подставляет данные из таблицы oc_monitoring.

Очистка старых файлов

Excel_Daily::cleanup_old_files() — удаляет xlsx-файлы старше N дней (по умолчанию 14). Вызывается в cron-скрипте.
