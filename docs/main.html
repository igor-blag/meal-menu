Мониторинг питания — документация плагина

WordPress-плагин для управления школьным меню, генерации Excel-файлов для ФЦМПО и публикации информации для родителей.

Версия: 1.0.0 | Text Domain: meal-menu | PHP: 8.0+ | WP: 6.3+

Структура модулей

  • 1. Активация и база данных — создание таблиц, seed-данные, структура БД
  • 2. Ядро плагина — Core, Roles, хуки, админ-меню, AJAX
  • 3. Календарь питания — админ-страница календаря, попап дня, модалка файлов
  • 4. Шаблоны циклов — список шаблонов, редактор блюд, интернат, дропзона
  • 5. Настройки пищеблока — организация, отделения, учебный год, каникулы
  • 6. Настройки плагина — SMTP, публикация файлов, импорт/экспорт, сброс данных
  • 7. Общественный контроль питания — 7 разделов ФИС ФРДО, загрузка файлов
  • 8. Импорт меню — загрузка xlsx, предпросмотр, подтверждение
  • 9. Публичная часть — шорткоды для родителей
  • 9б. Блок Гутенберг — блок «Календарь питания» для редактора
  • 10. Excel-генерация — ежедневные, tm, kp, OC, импорт
  • 11. Cron и Email — ежедневная проверка, SMTP, напоминания
  • 12. Тематическая система — палитры, стили, кастомизация
  • 13. Публикация XLSX в /food/ — копирование файлов в корневую папку food
  • 14. Летний лагерь — отдельное меню для пришкольного лагеря

Быстрый старт

  1. Установить и активировать плагин
  2. Перейти в Питание → Настройки пищеблока, настроить отделения
  3. Создать шаблоны циклов в Питание → Шаблоны (изначально пусто)
  4. Заполнить календарь в Питание → Календарь
  5. Настроить SMTP и путь публикации в Питание → Настройки плагина
  6. Опубликовать страницы с шорткодом [meal_calendar] или блоком «Календарь питания» в Гутенберге
