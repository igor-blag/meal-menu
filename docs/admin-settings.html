5. Настройки пищеблока

Файл: templates/admin/page-kitchen-settings.php

AJAX: includes/ajax/ajax-save-settings.php

Разделы

Образовательная организация

Название организации — отображается в шапке Excel-файлов и на публичных страницах.

Тип учреждения — выбор «Школа» или «Детский сад». При первом выборе автоматически создаются типовые отделения. При смене типа существующие отделения заменяются на типовые для выбранного типа.

Для детского сада скрыты: публикация Excel, каникулы, утверждающее лицо, общественный контроль питания.

Отделения (школа)

Типовые отделения для школы:

  • Дошкольное отделение — выключено по умолчанию, интернатный режим, без каникул
  • Начальная школа — включено, публикация xlsx
  • Основная школа — включено, публикация xlsx
  • Средняя школа — выключено по умолчанию

Каждое отделение имеет:

  • Включено/выключено — чекбокс активации
  • Название — отображается в Excel как «Отд./корпус»
  • Рабочие дни — выбор дней недели (Пн–Вс). Отключается при объединении
  • Интернат — добавляет полдник, ужин, 2-й ужин
  • Публикация xlsx — включение/отключение генерации Excel
  • Без каникул — режим круглогодичной работы
  • Постфикс файлов — суффикс в имени xlsx
  • Объединить календарь с — привязка к другому отделению
  • Летний лагерь — даты, рабочие дни, интернат, публикация

Отделения (детский сад)

Типовые отделения для детского сада:

  • Ясельная группа — дети до 3 лет, интернатный режим, без публикации
  • Основная группа — дети старше 3 лет, интернатный режим, без публикации

Для детсада скрыты опции: публикация xlsx, постфикс, объединение календарей, интернат, без каникул.

Создание отделения

Кнопка «+ Добавить отделение» — поля Название, Код (авто-транслитерация из названия), Постфикс (только для школ).

Учебный год и каникулы

Только для школ. Начало/конец учебного года, сброс цикла после каникул, редактирование каникул и праздников.

Утверждающее лицо

Только для школ. Должность и ФИО — отображаются в шапке типового меню (tm-файл).

Хранение

Тип учреждения (institution_type) хранится в таблице wp_meal_kitchen_settings.
