4. Шаблоны циклов

Файлы: templates/admin/page-templates.php, templates/admin/page-template-edit.php

POST-обработчики: admin_post_meal_save_template, admin_post_meal_add_template, admin_post_meal_delete_template

AJAX: wp_ajax_meal_import_dropzone, wp_ajax_meal_import_tm, wp_ajax_meal_bulk_delete_templates

Список шаблонов (page-templates)

  • Табы для переключения между типами школ
  • Таблица: №, Название, количество блюд по приёмам пищи (колонки формируются динамически — отображаются только те приёмы, для которых есть хотя бы одно блюдо)
  • Кнопки: «Изменить» → редактор, «✕» → удалить, «Удалить выбранные»
  • Множественное выделение чекбоксами и удаление выбранных
  • Кнопка «+ Добавить день»
  • Дропзона — перетащите XLSX-файлы меню для создания новых дней цикла (пакетная загрузка)
  • Импорт из TM-файла — панель ниже дропзоны. Загружает файл типового меню (.xlsx), парсит все дни цикла, заменяет существующие шаблоны. Работает для обычных отделений и летнего лагеря
  • При активации плагина шаблоны не создаются — изначально пусто
  • Вкладка «Летний лагерь» — показывается, если в Настройках пищеблока включена опция «Летний лагерь» для Начальной школы. Шаблоны лагеря хранятся в отдельных таблицах

Редактор шаблона (page-template-edit)

Форма редактирования блюд для каждого дня цикла:

  • Флаг интерната — включает секции Полдник, Ужин, Ужин 2 (может быть принудительно включён настройками отделения)
  • Секции приёма пищи: Завтрак, Завтрак 2, Обед (Полдник, Ужин, Ужин 2 для интерната)
  • Поля строки: Раздел, № рец., Блюдо, Выход (г), Цена, Ккал, Белки, Жиры, Углеводы
  • Добавление строки — кнопка «+ Добавить блюдо»
  • Удаление строки — кнопка ✕
  • TM-файл: для sm-шаблонов сохраняется дата утверждения и auto-генерируется typical menu xlsx

Бизнес-логика

Цикл — это N-дневная последовательность шаблонов (обычно 10–14 дней). Длина цикла настраивается в настройках отделения. При изменении длины автоматически добавляются или удаляются пустые шаблоны.
