1. Активация и база данных

Файлы: includes/class-activator.php, includes/class-db.php

Создание таблиц

При активации плагина Activator::activate() создаёт таблицы с префиксом wp_meal_:

wp_meal_users           — учётные записи (дублирует WP users, для email-токенов)
wp_meal_email_tokens    — коды подтверждения email (setup/reset)
wp_meal_templates       — шаблоны дней цикла (14 × school_type)
wp_meal_items           — блюда шаблона с nutritional data
wp_meal_calendar        — привязка шаблонов к датам (date, school_type, template_id, school, dept, is_cycle_start, iterate_number)
wp_meal_kitchen_settings — настройки организации
wp_meal_departments     — отделения (школы/корпуса), включая merged_with, has_summer_camp, camp_* поля
wp_meal_vacations       — каникулы по учебным годам, включая actual_date
wp_meal_oc_monitoring   — данные общественного контроля
wp_meal_camp_templates  — шаблоны циклов летнего лагеря
wp_meal_camp_items      — блюда шаблонов летнего лагеря
wp_meal_camp_calendar   — календарь летнего лагеря (даты → шаблоны)

Создание через $wpdb->query('CREATE TABLE IF NOT EXISTS ...') — совместимо с MySQL и SQLite (Playground).

При каждом запросе Core::ensure_tables() проверяет наличие колонок actual_date (vacations), iterate_number (calendar) и camp-таблиц, добавляя их через ALTER TABLE / CREATE TABLE при необходимости.

Seed-данные

При первом запуске заполняются:

  • 42 шаблона (14 дней × 3 типа: sm, main, ss)
  • Строка kitchen_settings (id=1)
  • 4 отделения (preschool, sm, main, ss)
  • Строка oc_monitoring (id=1)

Класс DB

Meal_Menu\DB — порт всех функций из оригинального src/db.php (652 строки) с PDO на $wpdb:

  • get_templates/get_template — CRUD шаблонов (основные и camp)
  • get_template_items/save_template_items — блюда шаблона (основные и camp)
  • get_calendar_day/month/year — выборка календаря (основные и camp)
  • save_calendar_day/delete_calendar_day/bulk_save_calendar — управление датами (основные и camp)
  • assign_cycle — автозаполнение цикла (основные и camp)
  • get_enabled_departments/save_department — управление отделениями
  • get_vacations/add_vacation — управление каникулами
  • get_current_period — вычисление четвертей/полугодий
  • get_oc_monitoring/save_oc_monitoring — ОК данные

Все методы используют prepared statements через $wpdb->prepare().
