Летний лагерь

Опция «Летний лагерь» доступна для отделения Начальная школа (sm) в Настройках пищеблока.

Позволяет вести отдельное меню для пришкольного лагеря в летний период с собственными шаблонами, календарём и генерацией файлов.

Включение

  1. Перейти в Питание → Настройки пищеблока
  2. Выбрать отделение Начальная школа
  3. Включить опцию «Летний лагерь»
  4. Заполнить даты начала и окончания лагеря, рабочие дни недели, интернат (принудительно для всех шаблонов лагеря) и публикацию xlsx

Отдельные таблицы БД

Данные лагеря хранятся в отдельных таблицах (не пересекаются с основными):

wp_meal_camp_itemsБлюда шаблонов лагеря
wp_meal_camp_calendarКалендарь лагеря (даты → шаблоны)

Админ-страницы

Шаблоны (Питание → Шаблоны → Летний лагерь)

  • Отдельная вкладка «Летний лагерь» (показывается, если в настройках включён лагерь)
  • Создание, редактирование, удаление шаблонов лагеря
  • Импорт из XLSX через дропзону — создаёт шаблон лагеря

Календарь (Питание → Календарь → Летний лагерь)

  • Вкладка «Летний лагерь» активна первой в летний период (если лагерь работает в текущем месяце)
  • В период лагеря на фронте показывается только вкладка лагеря (остальные отделения скрыты)
  • Отображаются только даты внутри интервала лагеря (camp_start_date…camp_end_date). Даты вне интервала затенены, не кликаются, подписаны «вне смены»
  • Однодневные праздники в пределах интервала (например, День России 12 июня) отображаются как выходные. Многодневные каникулы скрыты
  • Те же операции: назначение дня цикла, выходной, заполнить месяц, создать файлы
  • «Заполнить месяц» использует рабочие дни лагеря (camp_workdays), начинается с меню №1, игнорирует даты вне интервала
  • «Заполнить до конца месяца» не выходит за camp_end_date

Настройки пищеблока

  • Карточка Начальной школы содержит блок «Летний лагерь» с чекбоксом, датами, рабочими днями, интернатом и публикацией

Excel-генерация

Файлы лагеря имеют те же имена, что и файлы Начальной школы (перезаписывают их):

  • {YYYY-MM-DD}-sm.xlsx — ежедневное меню
  • kp{YYYY}.xlsx — годовой план-график
  • tm{YYYY}-sm.xlsx — типовое меню

Фронт (шорткод/блок)

  • Шорткод [meal_calendar camp="1"] — календарь лагеря
  • В летний период авто-определение: если текущая дата внутри лагерного периода, календарь показывает только лагерь
  • AJAX-эндпоинты: admin-ajax.php?action=meal_get_calendar&meal_camp=1
  • AJAX-эндпоинт дня: admin-ajax.php?action=meal_get_day_menu&camp=1

Методы БД (DB)

is_camp_period(type)                          — работает ли лагерь сейчас
is_camp_period_for_month(type, year, month)   — работает ли лагерь в указанном месяце
get_camp_templates(type)                       — все шаблоны лагеря
get_camp_template(id)                          — один шаблон лагеря
add_camp_template(type)                        — создать шаблон лагеря
delete_camp_template(id)                       — удалить шаблон лагеря
get_camp_templates_ordered(type)               — шаблоны в виде [day_number => id]
get_camp_cycle_length(type)                    — количество шаблонов в цикле
get_camp_template_items(template_id)           — блюда шаблона лагеря
save_camp_template_items(template_id, items)   — сохранить блюда шаблона лагеря
get_camp_calendar_day(date, type)              — запись календаря лагеря на дату
get_camp_calendar_month(year, month, type)     — календарь лагеря за месяц
get_camp_calendar_range(from, to, type)        — календарь лагеря за диапазон
get_camp_calendar_year(year, type)             — календарь лагеря за год
save_camp_calendar_day(...)                    — сохранить запись календаря лагеря
delete_camp_calendar_day(date, type)           — удалить запись календаря лагеря
assign_camp_cycle(...)                         — заполнить цикл лагеря на диапазон
bulk_save_camp_calendar(days, type)            — массовое сохранение календаря лагеря
set_camp_template_boarding(id, is_boarding)    — установить флаг интерната для шаблона лагеря
