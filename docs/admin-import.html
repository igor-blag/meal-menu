7. Импорт меню

Файл: templates/admin/page-import.php

Класс: includes/class-importer.php

Процесс импорта

  1. Выбор шаблона — клик по дню цикла на странице импорта
  2. Загрузка файла — выбор .xlsx файла для загрузки
  3. Предпросмотр — парсинг xlsx, отображение таблицы блюд
  4. Подтверждение — сохранение блюд в БД, редирект в редактор

Временный файл сохраняется в wp-content/uploads/meal-menu/ через WordPress Transients API.

Парсинг xlsx

Meal_Menu\Importer::parse($filepath) загружает xlsx через PhpSpreadsheet и извлекает строки данных (начиная с 4-й строки).

Маппинг русских заголовков на meal_type:

Завтрак → breakfast, Завтрак 2 → breakfast2, Обед → lunch,
Полдник → afternoon_snack, Ужин → dinner, Ужин 2 → dinner2

Строки с пустыми названиями блюд и разделов пропускаются.
