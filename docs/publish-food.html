12. Публикация XLSX в /food/

Доработка: 2026-06-03

Все сгенерированные XLSX-файлы автоматически копируются в папку /food/ корневого каталога WordPress (рядом с wp-config.php). Это нужно для интеграции с внешним мониторинговым ботом ФЦМПО, который забирает файлы из https://school.ru/food/*.xlsx.

Как это работает

  1. Функция meal_food_dir() (в meal-menu.php) возвращает путь к папке публикации. Сначала проверяет опцию meal_food_dir, при пустом значении — ABSPATH . 'food/'.
  2. Функция meal_publish_file($filepath) копирует готовый XLSX в эту директорию.
  3. Каждый Excel-генератор вызывает meal_publish_file() после сохранения файла в штатную папку wp-content/uploads/meal-menu/.

Настройка через админку

Поле «Путь к папке публикации» находится на странице Питание → Настройки в панели «Публикация XLSX-файлов».

  • Оставьте поле пустым — будет использован путь по умолчанию:
  • Укажите свой путь, например /home/site/public_html/food или C:/inetpub/wwwroot/food
  • Трейлинг-слеш не обязателен — добавляется автоматически

Программная конфигурация

Путь можно переопределить через фильтр (фильтр срабатывает только при пустой опции):

add_filter( 'meal_food_dir', function() {
    return '/custom/path/to/food/';
} );

Или напрямую через update_option('meal_food_dir', '/custom/path').

Очистка

Excel_Daily::cleanup_old_files() удаляет устаревшие XLSX-файлы и из wp-content/uploads/meal-menu/, и из папки публикации. Период хранения (по умолчанию 14 дней) настраивается опцией meal_delete_after_days.

Права доступа

Папка публикации должна быть доступна для записи веб-сервером (chmod 755 или 775). Плагин создаёт её автоматически при первой публикации через wp_mkdir_p().
