3. Календарь питания

Файл: templates/admin/page-calendar.php

AJAX: includes/ajax/ajax-save-day.php

Назначение

Главный рабочий экран администратора. Позволяет назначать шаблоны циклов на конкретные даты.

Структура страницы

  • Табы — переключение между отделениями. Если в настройках отделение объединено с другим (merged_with), вкладка цели отображается один раз, с названиями обоих отделений
  • Навигация по месяцам — ← Январь 2025 →
  • Сетка календаря — 7 колонок (Пн–Вс)
  • Цветовая маркировка: зелёный (есть меню), бежевый (выходной), сиреневый (каникулы)
  • Кнопки: Заполнить месяц, Создать файлы, Файлы

Попап дня

При клике на ячейку дня открывается попап с действиями:

  • Установить день цикла N — назначает шаблон с номером N на эту дату
  • Выходной — помечает день как нерабочий (template_id = null)
  • Очистить — удаляет запись календаря
  • Применить цикл — заполняет рабочие дни циклами начиная с заданного дня

AJAX-действия (save-day)

save        — сохранить/обновить день + сгенерировать xlsx
delete      — удалить запись календаря
apply_cycle — заполнить диапазон дат циклами
bulk_save   — массовое сохранение массива дней
recalc_period — пересчитать текущий период
generate_files — создать Excel для всех дней месяца + kp

Модалка файлов

Показывает список сгенерированных xlsx-файлов за текущий месяц с разбивкой по отделениям.
