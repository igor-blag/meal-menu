Блок Гутенберг — Календарь питания

Файлы: blocks/meal-calendar/
Регистрация: Core::register_blocks() в includes/class-core.php

Назначение

Блок «Календарь питания» (meal-menu/calendar) заменяет шорткод [meal_calendar] в редакторе Гутенберг. Позволяет выбирать тип школы, палитру, макет и отображение спойлера общественного контроля напрямую из интерфейса редактора.

Атрибуты

  • type (string) — тип школы (sm, main и т.д.). Пусто — первый доступный.
  • palette (string) — палитра оформления. Пусто — глобальная настройка.
  • layout (string) — макет оформления. Пусто — глобальная настройка.
  • show_oc (boolean) — показывать спойлер общественного контроля. По умолчанию true.

Как это работает

В редакторе

  • Placeholder с выбором типа школы
  • После выбора — AJAX-превью календаря через admin-ajax.php?action=meal_get_calendar
  • InspectorControls: тип школы, палитра (7 шт.), макет (3 шт.), переключатель OC
  • Блок выделяется кликом, используется useBlockProps

На фронтенде

  • Dynamic block — рендерится через render.php
  • Используется существующий метод Core::shortcode_calendar()
  • CSS из public.css + themes.css
  • JavaScript (public.js) — AJAX-навигация по месяцам и модалка меню дня

Сборка

npm install
npm run build     # прод
npm run start     # dev-режим с вотчером

Точка входа: blocks/meal-calendar/src/index.js
Результат: blocks/meal-calendar/build/index.js + index.asset.php

Файловая структура

blocks/meal-calendar/
├── block.json              # регистрация блока
├── src/index.js            # edit-компонент (React)
├── build/index.js          # скомпилированный JS
├── build/index.asset.php   # зависимости (wp-blocks, wp-components и т.д.)
└── render.php              # render_callback (PHP)

Зависимости (asset.php)

react-jsx-runtime, wp-block-editor, wp-blocks, wp-components, wp-element, wp-i18n, wp-url

Примечания

  • Шорткод [meal_calendar] продолжает работать для обратной совместимости
  • Если у блока не выбран тип школы — используется первое доступное отделение
  • Палитра и макет «По умолчанию» берутся из глобальных настроек (Оформление)
  • AJAX-эндпоинты meal_get_calendar и meal_get_day_menu переиспользуются
