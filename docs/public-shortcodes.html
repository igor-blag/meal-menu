8. Публичная часть (шорткоды)

Файлы: includes/class-core.php (метод render_calendar_body), templates/public/day.php

CSS: assets/css/public.css (структурные классы) + assets/css/themes.css (палитры/стили)

Архитектура

Все публичные шаблоны используют BEM-подобные CSS-классы вместо inline-стилей. Цвета и шрифты задаются через CSS-переменные, которые переопределяются выбранной темой.

Каждый шаблон обёрнут в .meal-wrapper.palette-*.layout-* — это определяет, какие CSS-переменные активны. Классы палитры и стиля берутся из get_option('meal_theme_palette') и get_option('meal_theme_layout').

[meal_calendar] / блок «Календарь питания»

Публичный календарь питания для родителей. Рендерится методом Core::shortcode_calendar() + Core::render_calendar_body().

С версии 1.0.0 доступен также Gutenberg-блок «Календарь питания» (meal-menu/calendar). Блок поддерживает выбор типа школы, палитры, макета и отображение OC-спойлера. Подробнее: документация блока.

  • AJAX-навигация: переключение месяцев и вкладок отделений без перезагрузки страницы (admin-ajax.php?action=meal_get_calendar)
  • Модалка: клик по ячейке с меню открывает детальное меню дня через AJAX
  • Спойлер ОК: под календарём встроен <details> с общественным контролем питания
  • Адаптивность: на мобильных — горизонтальный скролл сетки, скрытие подписей, вся ячейка кликабельна
  • Цветовая маркировка: зелёный (меню), голубой (каникулы), розовый (праздник), серый (выходные)

[meal_day date="2025-06-01" type="sm"]

Детальное меню на конкретный день с таблицей nutritional data.

  • CSS-классы: .meal-block, .meal-block-title, .meal-table, .section-row, .num, .meal-notice, .meal-download-btn
  • Группировка по приёмам пищи (Завтрак, Завтрак 2, Обед, ...)
  • Секции внутри приёма (закуска, 1 блюдо, 2 блюдо, гарнир, напиток)
  • Ссылка на скачивание xlsx (если файл существует)

Шрифты

Source Serif 4 (с засечками) — по умолчанию. Файлы .ttf в assets/fonts/, подключаются через @font-face в public.css. Шрифт можно изменить через выбор стиля (sans-serif для Modern и Air).
