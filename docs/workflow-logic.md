# Логика работы с плагином

## 0. Шаблоны и объединение отделений

- В **«Питание → Шаблоны»** заполнить собственный цикл каждого отделения. Блюда, порции, цены и КБЖУ принадлежат отделению, даже если календарь общий.
- **«Объединить календарь с»** означает общее расписание: даты питания, номера дней цикла, отметки выходных и признаки начала/сдвига цикла. Календарь хранится у отделения, указанного в этой настройке; повторно записывать его каждому участнику не нужно.
- Например, при `sm → main` дата и номер дня берутся из календаря `main`. Для дня № 3 начальная школа `sm` использует свой шаблон № 3, старшие `main` — свой. Совпадать должен `day_number`, а не ID шаблона.
- Проверить, что у каждого объединённого отделения есть собственные шаблоны для всех номеров общего цикла. Если нужного шаблона нет, меню не отображается и новый ежедневный XLSX этого отделения не создаётся; подстановки блюд другого отделения нет.
- Летний лагерь использует отдельные шаблоны и календарь; объединение обычных календарей на него не распространяется.

## 1. Подготовка месяца

- В **«Питание → Календарь»** выбрать отделение или общую вкладку объединённых отделений.
- Отметить **выходные дни** в текущем месяце, если они отличаются от обычного расписания.
- При необходимости отметить субботы/воскресенья как **рабочие**.
- Для выходных дней есть чекбокс **«Учитывать в нумерации»**: питание не проводится, но номер дня меню увеличивается и сдвигает цикл.
- При объединении все эти изменения относятся к общему календарю.

## 2. Заполнение месяца

- Выбрать первый рабочий день месяца → в попапе указать **номер дня меню** → нажать **«Заполнить до конца месяца»**.
- Если в середине месяца расписание изменилось, выбрать нужную дату, изменить номер меню и снова заполнить остаток месяца.
- Для объединённых отделений номера назначаются по циклу источника календаря. Менять блюда или порции нужно отдельно в шаблонах соответствующего отделения.
- После заполнения проверить, что для каждой даты задано меню, выходной или каникулы. Отсутствие локального шаблона нужно исправлять в **«Шаблонах»**, а не заменой меню другим отделением.
- Каникулы заполнение пропускает: даты из раздела **«Каникулы»** не получают номер дня и не расходуют его — цикл продолжается со следующего учебного дня. Исключение — отделения с интернатным режимом: у них питание и в каникулы.
- Кнопка **«Заполнить до конца месяца»** в попапе перезаписывает уже назначенные дни, но каникулы не затрагивает. Кнопка **«Заполнить [месяц]»** в панели над сеткой заполняет только пустые дни.

## 3. Генерация файлов

- Мониторинг питания получает данные из опубликованных Excel-файлов.
- После заполнения календаря нажать **«Создать файлы»** для выбранного месяца.
- Для объединённой группы ежедневные XLSX создаются отдельно для каждого отделения с включённой публикацией. Общий календарь определяет дату и номер дня, собственный шаблон отделения — блюда и показатели.
- Файл TM формируется по собственным шаблонам каждого отделения группы. План-график KP использует календарь источника объединения.
- Публичные меню, включая открытие меню дня из календаря, используют выбранное посетителем отделение и его собственные шаблоны.
- Дни каникул не попадают в ежедневные XLSX и KP. Если меню у дня-каникула всё же стоит (например, каникулы добавили после заполнения), файл на этот день не создаётся, а календарь всё равно показывает «каникулы». Чтобы привести данные в порядок, очистите такой день в календаре, удалите его старые XLSX через раздел **«Файлы»** и создайте файлы заново.

## 4. Вкладки отделений

- Независимые календари заполняются отдельно.
- Объединённый календарь редактируется один раз на общей вкладке с названиями отделений; отдельная вкладка источника скрывается.
- В разделе **«Шаблоны»** отделения остаются отдельными, чтобы редактировать разные порции и состав меню.
- Наличие опубликованных файлов проверяется по публичной папке, по умолчанию `/food/`. После удаления файла календарь больше не должен считать его опубликованным.

## 5. Копирование между независимыми календарями

- Для переноса расписания используются действия **«Заполнить как в [название отделения]»** и **«Заполнить как … и сгенерировать файлы»**.
- Копирование сопоставляет шаблоны по номеру дня. Блюда целевого отделения остаются в его собственных шаблонах.
- Объединённым календарям регулярное копирование между участниками не требуется: они читают одно расписание.

## 6. После исправления подмены меню объединённых отделений

1. Обновить плагин.
2. В **«Шаблонах»** проверить, что в каждом отделении загружен его собственный цикл. В образцах из `reference/` суффикс `-sm` обозначает начальную школу, файл без суффикса — старших; импортировать их в соответствующие вкладки.
3. Проверить настройку **«Объединить календарь с»** и заполненность общего календаря. Повторно назначать даты не требуется, если расписание и номера цикла были верны.
4. Нажать **«Создать файлы»** для каждого затронутого месяца. Обновление кода не меняет и автоматически не удаляет уже созданные XLSX в загрузках и `/food/`. Если собственного шаблона пока нет и пересоздать файл нельзя, удалить ошибочный XLSX через раздел **«Файлы»**, чтобы старая публичная копия не оставалась доступной.
5. Очистить кеш страниц/CDN, если он используется. Проверить меню дня и скачать свежие XLSX отдельно для младших и старших: одинаковый номер дня должен давать соответствующие отделению порции и КБЖУ.

Для разработчика: регрессия общего календаря проверяется командой `php tests/run.php`; изменённые PHP-файлы дополнительно проверяются через `php -l`.
