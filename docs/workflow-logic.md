# Логика работы с плагином

## 0. Подготовка месяца
- Отметить **выходные дни** в текущем месяце (если есть)
- При необходимости отметить **субботы/воскресенья как рабочие**
- Для выходных дней есть чекбокс **«Учитывать в нумерации»** — если день не кормим, но номер дня меню всё равно увеличивается (сдвиг цикла)

## 1. Заполнение месяца
- Выбрать первый рабочий день месяца → в попапе указать **номер дня меню** (от какого числа отталкиваться) → нажать **«Заполнить до конца месяца»**
- Если в середине месяца всё поменялось — кликнуть на произвольный день, изменить номер меню и нажать **«Заполнить до конца месяца»** — остаток пересчитается

## 2. Пустые ячейки
- После заполнения не должно оставаться пустых клеток: либо номер меню, либо выходной, либо каникулы
- Если день пустой — подсветить ячейку **красным**, но **только если в месяце уже были манипуляции** (если месяц новый — не раздражать администратора)

## 3. Генерация файлов
- Мониторинг питания работает через парсинг Excel-файлов
- После заполнения календаря → **«Создать файлы»**

## 4. Вкладки отделений
- Заполняем для каждого отделения календарь отдельно
- Если в настройках включено **«Объединить календарь с»** — вкладка цели показывается один раз с названиями обоих отделений (вкладка отделения-цели скрыта)
- Если одно отделение заполнено и файлы сгенерированы — подсветить **красным вкладки незаполненных отделений** (убрать подсветку, когда заполнены и файлы есть)

## 5. Копирование между отделениями
- При переключении на другое отделение копировать данные о **выходных и рабочих днях** из первого заполненного
- Если циклы совпадают по номерам — добавить кнопки:
  - **«Заполнить как в [название отделения]»**
  - **«Заполнить как … и сгенерировать файлы»**
