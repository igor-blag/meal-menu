2. Ядро плагина

Файл: includes/class-core.php, includes/class-roles.php

Core::init()

Запускается на plugins_loaded. Регистрирует все хуки:

  • init — шорткоды
  • admin_menu — 7 страниц админ-панели
  • admin_enqueue_scripts — CSS/JS для админки
  • wp_enqueue_scripts — CSS для публичных страниц
  • wp_ajax_meal_* — 5 AJAX-обработчиков
  • admin_post_meal_* — 3 POST-обработчика
  • phpmailer_init — конфигурация SMTP
  • meal_daily_check — WP-Cron

Админ-страницы

Календарь     → meal-calendar    → page-calendar.php
Шаблоны       → meal-templates   → page-templates.php / page-template-edit.php
Импорт        → meal-import      → page-import.php
ОК Питания    → meal-oc          → page-oc.php
Настройки     → meal-settings    → page-settings.php
Помощь        → meal-help        → page-help.php
Файлы         → meal-files       → page-files.php

Доступ к страницам — через capability manage_meal_menu.

Роли

Meal_Menu\Roles создаёт роль meal_manager с capability manage_meal_menu. Администратору (administrator) capability добавляется автоматически.

Шорткоды

  • [meal_calendar type="sm"] — публичный календарь питания
  • [meal_day date="2025-06-01" type="sm"] — меню на день
  • [meal_menu type="sm"] — типовое меню (цикл)
  • [meal_oc] — общественный контроль питания

AJAX-эндпоинты

meal_save_day       → ajax-save-day.php     — сохранение/удаление/цикл/файлы
meal_save_settings  → ajax-save-settings.php — настройки, отделения, каникулы
meal_save_oc        → ajax-save-oc.php      — сохранение ОК
meal_upload_oc      → ajax-upload-oc.php    — загрузка файлов для ОК
meal_list_files     → ajax-list-files.php   — список сгенерированных xlsx

Все проверяют nonce (meal_menu_nonce) и capability.

Обработчики admin-post

admin_post_meal_save_template   — сохранение шаблона (POST форма)
admin_post_meal_add_template    — добавление дня цикла
admin_post_meal_delete_template — удаление шаблона
