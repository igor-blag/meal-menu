2. Ядро плагина

Файлы: includes/class-core.php, includes/class-shortcodes.php, includes/class-admin.php, includes/class-ajax.php, includes/class-roles.php

Архитектура (v2.0)

Класс Core отвечает только за инициализацию, блоки, крон, SMTP и миграции БД. Функциональность разделена на три отдельных класса, каждый сам регистрирует свои хуки в конструкторе:

  • Shortcodes — [meal_calendar], [meal_day], рендер календаря и OC-спойлера
  • Admin — регистрация страниц админки, enqueue ассетов, admin_post-обработчики
  • Ajax — все wp_ajax_* и wp_ajax_nopriv_* обработчики

Core::init()

Запускается на plugins_loaded. Создаёт экземпляры Shortcodes, Admin, Ajax и регистрирует оставшиеся хуки:

  • init — регистрация Gutenberg-блока
  • wp_enqueue_scripts — CSS/JS для публичных страниц
  • phpmailer_init — конфигурация SMTP
  • meal_daily_check — WP-Cron

Админ-страницы

Календарь      → meal-calendar    → page-calendar.php
Шаблоны        → meal-templates   → page-templates.php / page-template-edit.php
ОК Питания     → meal-oc          → page-oc.php (только для школ)
Настройки п/б  → meal-settings    → page-kitchen-settings.php
Настройки пл.  → meal-plugin-settings  → page-plugin-settings.php
Оформление     → meal-theme       → page-theme.php
Помощь         → meal-help        → page-help.php
Файлы          → meal-files       → page-files.php

Страница «ОК Питания» скрыта для детских садов. Доступ к страницам — через capability manage_meal_menu.

Роли

Meal_Menu\Roles создаёт роль meal_manager с capability manage_meal_menu. Администратору (administrator) capability добавляется автоматически.

Шорткоды

  • [meal_calendar type="sm"] — публичный календарь питания (класс Shortcodes)
  • [meal_day date="2025-06-01" type="sm"] — меню на день

Шорткоды [meal_menu] и [meal_oc] удалены: типовое меню доступно через клик по ячейке календаря, а ОК встроен в календарь как спойлер (скрыт для детсадов).

AJAX-эндпоинты (класс Ajax)

meal_save_day       → ajax-save-day.php       — сохранение/удаление/цикл/файлы
meal_save_settings  → ajax-save-settings.php   — настройки, отделения, каникулы
meal_save_oc        → ajax-save-oc.php         — сохранение ОК
meal_upload_oc      → ajax-upload-oc.php       — загрузка файлов для ОК
meal_list_files     → ajax-list-files.php      — список сгенерированных xlsx
meal_delete_file    — удаление файла
meal_cleanup_files  — очистка старых файлов
meal_save_theme     — сохранение палитры/макета
meal_get_day_menu   — HTML меню дня для модалки (публичный)
meal_get_calendar   — HTML тела календаря (AJAX-навигация)
meal_import_dropzone — импорт xlsx через дропзону
meal_import_tm       — импорт TM-файла
meal_bulk_delete_templates — массовое удаление шаблонов
— AI Photo Import:
meal_photo_upload       → ajax_photo_upload       — загрузка фото
meal_photo_analyze      → ajax_photo_analyze      — отправка в AI, JSON с блюдами

Все проверяют nonce (meal_menu_nonce) и capability.
