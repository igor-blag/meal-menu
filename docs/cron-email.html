10. Cron и Email-уведомления

Файл: includes/class-core.php (метод run_daily_cron)

Хук: meal_daily_check

WP-Cron

При активации плагина регистрируется ежедневное событие WP-Cron:

wp_schedule_event(time(), 'daily', 'meal_daily_check')

При деактивации событие снимается: wp_clear_scheduled_hook('meal_daily_check').

Что делает cron

  1. Считает количество последовательных заполненных рабочих дней начиная с завтрашнего (пропуская выходные и каникулы)
  2. Если заполнено ≤ 3 рабочих дня — отправляет email-напоминание администратору
  3. Email содержит: приветствие, описание проблемы, просьбу пополнить расписание

SMTP-конфигурация

На хуке phpmailer_init настройки SMTP из WordPress Options применяются к PHPMailer:

  • meal_smtp_host — SMTP-сервер
  • meal_smtp_port — порт (по умолчанию 587)
  • meal_smtp_user / meal_smtp_pass — учётные данные
  • meal_smtp_secure — шифрование (tls/ssl)
  • meal_mail_from / meal_mail_from_name — адрес и имя отправителя

Если SMTP-хост пустой — используется стандартный wp_mail() (PHP mail или SMTP другого плагина).

Очистка файлов

Cron также может вызывать Excel_Daily::cleanup_old_files() для удаления старых xlsx-файлов.
