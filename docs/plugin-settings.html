6. Настройки плагина

Файл: templates/admin/page-plugin-settings.php

AJAX: includes/ajax/ajax-save-settings.php

Разделы

Публикация XLSX-файлов

Путь к папке, куда копируются сгенерированные Excel-файлы. По умолчанию — /food/ в корне сайта. Настраивается через поле ввода или фильтр meal_food_dir.

Email-уведомления

  • Email администратора — на него приходят напоминания о незаполненных днях
  • Email отправителя и имя
  • SMTP-настройки (хост, порт, пользователь, пароль, шифрование)

При пустом хосте используется стандартный wp_mail().

Импорт / Экспорт данных

  • Экспорт JSON — скачивает все таблицы плагина и опции (SMTP, food_dir, тема) в JSON-файл
  • Импорт JSON — загружает JSON-файл, очищает таблицы и вставляет данные в правильном порядке (сначала родительские, потом дочерние)

Сброс данных плагина

Удаляет все таблицы (wp_meal_*) и создаёт их заново с настройками по умолчанию. Файлы плагина не затрагиваются. Требуется двойное подтверждение.

Действия

Все действия (сохранение, импорт, сброс) требуют права manage_options.
